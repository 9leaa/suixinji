CANVAS GUIDE

把架构摊开来看

移动与缩放

拖拽空白移动画布；滚轮、触控板捏合或双指缩放。按 F 显示完整场景，+ / − 缩放。

展开模块

直接拖拽模块拉开距离，连线会自动绕开节点。拖拽分组标题可移动整个分组；「还原布局」只重置当前场景。

追踪一条交互

点击模块突出它的直接关联；点击箭头或连线文字查看调用双方与用途。「全部关系」显示当前场景的所有关系。

逐步看业务流程

切换顶部场景，按步骤播放。场景保留上下文，当前步骤高亮；播放为逻辑演示，不代表实际请求严格串行。

实线：常规组件关系。虚线：按条件触发的关系。颜色区分职责，其中配置类关系使用棕色，但不一律画成虚线。修改后的模块位置会尝试保存在本地；「保存 HTML」可把当前布局一并导出，无需联网。
