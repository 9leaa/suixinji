# 控制台展示整理

- 处理结果与业务结果在流程图之前展示；查询等待步骤不计作记忆写入。
- 默认展示关键业务步骤，可切换全部调用；保留实际参数、返回值、候选和模型上下文。
- 独立阶段运行使用自己的标识、答案、耗时和任务信息；没有记录的指标标为未记录或未计时。
- 四类记忆库统一查看偏好、任务、语义、情景，支持类型、正文筛选和分页。
- 版本对比只使用已保存版本；原文明确标注为当前笔记，不用当前数据反推历史模型输入。遗忘来源沿用遮蔽规则。
- 记忆库和审批跟随当前查看空间，不读取发送表单的空间覆盖历史记录。
- 历史支持空间、关键词、状态、时间筛选及数据库分页；状态与详情使用相同的任务判断顺序。

验证：相关 Python 测试 42 项通过；JavaScript 语法与 Ruff 检查通过。使用独立的本地预览端口，核对真实历史查询、阶段切换、后台任务空态、审批空间、四类记忆库和原文版本对比。验证期间未发送业务消息、未审批或修改记忆，未部署现有服务。
