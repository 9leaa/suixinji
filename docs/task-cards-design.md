# 任务记忆卡片

分支：`codex/task-memory-cards`。任务改为专属结构，复用记忆主表、来源和版本机制。功能通过 `SUIXINJI_TASK_CARDS_ENABLED` 独立启用，默认关闭。

| 业务字段 | 含义 |
|---|---|
| `subject` | 执行人；省略时为用户，项目名称属于任务描述 |
| `task` | 动作和对象，不包含状态、截止时间或进展 |
| `instance` | 哪一次任务，例如第43周、第二轮；未说明为空 |
| `task_status` | 仅 `todo`（尚未结束）、`done`（已结束） |
| `closure_reason` | `completed`、`cancelled`、`abandoned`，原因未知为空；todo 必须为空 |
| `details` | 具体要求、进展、阻碍、时间、结果及补充说明 |

细节字段为 `id / kind / condition / description / source_ids`。kind 只分 `requirement / progress / blocker / time / outcome / note`，内容保留自然语言。系统另存细节有效性、原文片段和替代来源。细节变为历史不增加任务状态。

## 写入与身份

模型一次抽取任务专属字段；每条任务及每项细节都必须提供当前消息中的真实原文片段。程序绑定来源 ID、原消息、消息时间、指代来源。抽取元数据 `intent` 区分普通记录、明确新增、修改、重开，不属于业务状态。模型调用失败由通用 pending 保存现场并等待重试，不降级生成不可靠的新任务结构。

同主体、同任务、同轮次先精确关联；缺少轮次时保留全部同名候选，多个目标进入 pending。前文消息引用可缩小候选，但仍核验前文 ID 和原文。语义匹配使用现有混合检索，相关性不能直接授权更新。

- 周五改为周六交：原卡片、原 ID，替换截止细节，旧细节成为历史。
- 收到销售数据：明确解除旧阻碍后才将其设为历史，其他要求继续保留。
- 初稿完成：进展细节，提交任务仍为 todo。
- 取消或放弃：done，并保存结束原因；不能回答成“已完成”。
- 明确重开同一次任务：done → todo，清空当前结束原因，保留历史。
- 明确再做一次：新卡片，不重开旧任务。
- 未说明哪一次的完成消息：有多个目标则 pending，不选择最新一条。

关联模型只能选择已有目标、替换指定细节或使指定细节失效；新增细节自动追加。重复细节合并来源，不无约束重写整张卡片。较旧消息修改较新证据时进入 pending；不把写入时间当作用户事实时间。

卡片有固定的记忆 ID，标题、进展、截止时间不作为更新时重新计算的主键。语义匹配成功后保留原键；同类检索键与实例身份分开。明确新建同名任务使用独立 occurrence 标识。不同用户、执行人和轮次不互相更新。

## 存储、查询与兼容

结构保存在 `memories.scope_json.task_card`，结构版本为 `task-card-v1`。现有 `task_status` 列仍供筛选；检索文本由当前细节生成，更新复用数据库已有索引和向量刷新机制。模型只看到当前细节；时间线接口可以查看历史细节和版本。Ask V2 的最终证据包携带完整任务字段、原文与消息时间，并明确 done 不等于完成。

SQLite 与 PostgreSQL 均校验卡片版本，版本冲突重新读取并判断，最多尝试三次。状态同为 todo 也必须比较版本，不能把另一个人的进展当成重复消息丢掉。事务保存卡片、笔记来源、版本和裁决；裁决 ID 固定，重试不重复写入。任务卡片不走旧的“完成后归档相似任务”逻辑，避免影响其他轮次。

旧记录仍可读取。当执行人、任务身份及关联明确时，可在更新中沿用原记忆 ID 转成卡片，保留旧描述和版本。旧记录没有可靠消息时间或原文时标为未知，不能用记忆创建时间伪造来源时间。旧版 entity 被用作项目名等不兼容情况不自动猜测执行人；本次不提供全量迁移。

## 启用

1. 部署本分支代码。PostgreSQL 使用项目现有迁移至 `20261018_0016`（提供通用 workflow 表）；本次没有新增表或列。
2. 配置 `SUIXINJI_TASK_CARDS_ENABLED=true`，抽取模式使用 `SUIXINJI_MEMORY_EXTRACTOR_MODE=llm` 或 `hybrid`，重启相应服务。
3. 偏好开关独立配置。先在测试空间验证抽取与问答，再启用正式环境。

新结构需要模型抽取；旧规则路径或缺少新字段的输出会进入 pending，不冒充完整任务卡片。没有引入自动提醒、递归子任务、优先级或进度百分比。相对时间由模型结合原消息时间理解；截止时间保留为自然语言细节，本版不承诺按 `due_at` 精确筛选。

关闭开关只停止新结构写入，不回滚已有卡片；需要回退数据时使用启用前备份。
