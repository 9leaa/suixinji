# 评测数据集归档

本目录保存可分发、可重复导入的评测数据集压缩包：

- `suixinji_layer1_repaired_datasets.zip`
- `suixinji_layer1_remaining_datasets.zip`
- `suixinji_layer2_datasets_v1.zip`
- `suixinji_layer3_datasets_v1.zip`
- `suixinji_l1_l2_bridge_v1.zip`

解压后的执行数据、评分器与测试代码分别放在 `eval/layer1/`、`eval/layer2/`、`eval/layer3/` 和 `eval/l1_l2_bridge/`，不要把运行结果写回压缩包。
